Lei Geral de Proteção de Dados (Lei nº 13.709/2018)

O CineFood trata seus dados pessoais para viabilizar a reserva de poltronas, processamento seguro de pagamentos e entrega de alimentos no assento:

1. Dados Essenciais (Base Legal: Execução de Contrato):

Nome, e-mail, CPF (para emissão de nota fiscal e controle de meia-entrada) e histórico de ingressos.

2. Segurança de Pagamento:

Dados completos de cartão nunca são gravados em nossos servidores (ADR-002 / RNF-02).
